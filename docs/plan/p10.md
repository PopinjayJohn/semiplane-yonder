# P10 Security + Testing Strategy

## Goal
Secret safety + parser robustness proven by tests.

## Scope
- Threat model: player widening reads (search/snippets/tags/graph/SSE/replay/API/print/zip, traversal), CSRF/session fixation (incl. login POST), upload abuse (size/type), XSS via markdown (allowlist HTML). Login rate-limit (5 fails/5min per IP + per account, token bucket in memory, 15min lockout persisted in `login_attempts {ip, fails, locked_until}`) + session expiry (30d absolute, 24h sliding idle), EXIF strip, SVG blocklist.
- HTTP hardening: read/write/idle timeouts, body limits (5/10MB), in-memory token-bucket rate limiter, CSRF double-submit, trusted-proxy config for LAN vs reverse proxy. `slog` JSON to stderr + request IDs, secret content never logged.
- Tests: secret-leak matrix (GM / owner / editable-by-non-owner / other-player / guest / revoked-session × secret/non-secret / +/- / conflicted-file / embed-of-secret), fuzz goldmark extensions + frontmatter, `../` traversal vectors, conflict-file ACL tests.
- A11y tests: axe-core on P01 pages (no critical/serious), keyboard-only walkthrough script, token contrast check per theme, reduced-motion respected.
- Budgets enforced in CI: rendered pages <100KB HTML/CSS excl. vendored JS, VTT resync <1s LAN, axe clean on P01 pages (axe ≠ full AA — keyboard walkthrough covers the rest).
- CI matrix (GitHub Actions): `templ generate` + `git diff --exit-code`, `go vet`, `gofmt`, `golangci-lint`, unit + fuzz-short, 3-OS `goreleaser --snapshot`, axe on P01 pages.
- Logging: `edits_log` table (append-only who/what/when; secrets-advanced audit UI reads it, same schema). No PII in logs.

## Pass/fail
- Leak matrix green on every PR. Fuzz corpus in repo.

## Out
Audit UI (deferred to secrets-advanced), OAuth.
