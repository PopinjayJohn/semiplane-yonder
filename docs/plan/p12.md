# P12 Dice + Rolls Transport (ruleset-defined grammar)

## Goal
Deterministic, auditable roll events shared over SSE. Core carries opaque roll results plus a generic roller; it does not define what dice mean.

## Scope
- Core: generic dice engine (parse, `crypto/rand`, keep/drop, symbol-cancellation primitives) driven by base-declared `dice_types`, + `dice_logs` in SQLite + Datastar broadcast (P08 displays) + GM-blind vs party routing + replayable log (replay reads stored values, never re-rolls; every replayed event re-authorized against current viewer). Seeded RNG test-only.
- Grammar + faces + interpretation declared by Ruleset Base (P05) as config + data rules for the hand-rolled evaluator; core implements the mechanics. Overlay/homebrew may add dice or modify evaluation, never core code.
- Sheet modifier hook comes from P05 schema; P12 just passes context through. Intent names validated against active base by `rules lint`, never a global list. Mid-session toggle affects future rolls only (history pins modifier list).
- Validation: transport maxima (100 dice, 1000 faces/symbols per roll, 10 rolls/sec per authenticated user, per-IP bucket for guests) — bases may set lower values within them.

## Pass/fail
- Same transport carries a D&D numeric roll and a symbol-face roll with no core change; swap base -> new dice render.
- Grammar unit + property tests live with the ruleset, transport replay tests in core.

## Out
Ruleset-specific dice definitions + auto-calc (P05), VTT animation (P08).
