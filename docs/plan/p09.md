# P09 Distribution + Ops

## Goal
Single binary, offline-first, laptop + server.

## Scope
- `goreleaser` 3-OS builds, `go:embed`, pure-Go modernc driver (no cgo).
- Flags: `--vault`, `--data-dir` (default: sibling <vault>-data/ holding `<name>.index.db`, `<name>.app.db`, `.sessionkey`; never inside the vault), `--addr`. `init --bare` offline (creates GM account; scaffolds `campaign.yaml`, `README.md`, all special folders + `.keep`, vault `.gitignore` ignoring `*.db`/`.sessionkey` with explicit `!.keep` negations — dotfiles otherwise respected for `.obsidian/`); `init --template=` fetches versioned zip when online, cached. CLI: `serve` (default), `reindex` (index tables only), `reset-password` (bumps `session_version`), `rotate-session-key`, `transfer-ownership`, `archive-vault`, `clone-vault`, `rules lint`.
- Watcher ignores `*.db`, `.sessionkey`, and build dot-dirs only (never blanket dotfiles — `.obsidian/` and `.keep` must work). Conflict files are indexed (status + parent ACL) but excluded from search/links/graph/tags.
- Migrations: homegrown embedded SQL + `PRAGMA user_version`; rebuild-index command.
- Ops endpoints: `/healthz` + `/version` (version + build sha only, no vault names/counts) + documented log location. Graceful shutdown drains SSE before exit.
- One-click `Download vault zip` in UI (GM owns files; button prevents tears). No trash/versions in app.
- Client caching for table use: last-viewed sheet + static assets cache headers; server stays offline-first (no service-worker v1).
- Print: player-safe print stylesheet (secret-filtered) for handouts.
- Windows: path separators, case-insensitivity, long paths, `:8080` firewall note.

## Pass/fail
- Fresh laptop: download binary + `init --bare`, works with no internet.
- Index rebuild restores search/graph from vault alone; reindex never touches auth/app rows.

## Out
Auto-update, TLS termination, hosted SaaS.
