# P08 VTT MVP (last, non-negotiable)

## Goal
Minimal tactical map over SSE. No Foundry parity.

## Scope
- Background image + fog + tokens linked to character pages. Token move = debounced PATCH + SSE broadcast + full-state resync on reconnect.
- Dice tray + initiative list (grammar from P05 base, displayed here; tracker logic owned by initiative Feature, VTT renders + feeds token order).
- Secret zones / hidden tokens GM-only. Player positions filtered server-side. Visibility default lives in sidecar frontmatter; live hidden/visible overrides in SQLite (reset to sidecar on DB rebuild).
- A11y (WCAG AA): tokens also a keyboard-operable list (arrow-key move, text coordinates); fog/canvas has text equivalent; SSE updates use `aria-live=polite` (dice) / `assertive` (secret reveal); morphs never steal focus; redaction announced as "redacted".
- Run-mode hook: GM dashboard (P07) embeds initiative + token HP + quick-damage here; encounter spawn writes tokens + initiative in one action. VTT requires login (guests see nothing live); map-fragment URL + SSE event catalog + state-snapshot endpoint frozen as I2's exit contract.
- Cache policy: secret-gated responses `Cache-Control: private, no-store`; static vendor assets immutable + hashed; logout purges client cache; secret-flip triggers SSE invalidation of open views.
- Storage (locked Option A): grid calibration/size/rotation in sidecar `.md` frontmatter (Obsidian-visible, survives DB rebuild); live token positions/fog/visibility in the app DB (ephemeral, resync on load; index rebuilds never touch them; full data-dir loss resets to sidecar defaults, fog fail-closed to fully hidden). Images: png/jpg/pdf fully, webp stored-as-is, 5MB / 4000px cap. Windows path/case handling.
- Load test: 6 clients, hotel-WiFi simulation. No WS in v1 — if drag latency fails, degrade to click-to-move + throttle. Touch targets >=44px for tokens/dice on mobile.

## Pass/fail
- 6 browsers move tokens + fog without desync or secret leak.
- Offline LAN works, refresh resyncs.

## Out
Grid/lighting, smooth drag interpolation, voice/video, animation.

## Lane K implementation log (Phase 4, branch lane/K-vtt)

Delivered: `internal/vtt/` (map UI + state + render + HTTP + wire),
migration `0003_vtt_state`, 6-client load test, live smoke. No dashboard
code written or touched. Frozen I2 contract consumed verbatim (fragment URL,
snapshot endpoint + shape, all 10 SSE names, `vtt-map` target id).

- Sidecar: `maps/<mapID>.md` frontmatter `vtt-map:` block (new append-only
  key, Phase 4 amend) = background asset ref + grid {cols, rows, cell,
  offset-x/y, rotation} + `fog-default` + optional `tokens:` defaults.
  Broken values fall back field-by-field (never bricks the board).
- Fog Shape encoding (opaque string, meets VTT needs — no contract change
  filed): `v1;<cols>x<rows>;<x,y,w,h;...>` hidden-cell rects, clipped +
  canonicalized. Missing/empty/corrupt/grid-mismatched mask = fully hidden
  for EVERYONE incl. GM (fail closed, never fail open).
- Tokens: app-DB live rows (name/HP/link added by 0003); players move own
  linked tokens or unlinked extras; hidden tokens fully omitted for non-GMs
  (id/name/pos/HP/link); character links resolve per viewer (secret sheet
  paths never leak). HP potent: GM-only quick-damage (dashboard hook).
- Snapshot `Hidden=true` is served to GMs too on data loss (signal: "no
  trustworthy fog data"); an explicit full-cover mask serves `Hidden=false`
  + full rects. GM `reset` op reseeds tokens + fog from sidecar (P08
  "reset to sidecar"); index rebuilds provably never touch app-DB rows.
- Moves: PATCH JSON (250ms client debounce) + POST op envelope (move/hp/
  fog/spawn/initiative/reset/roll); CSRF double-submit incl. `X-CSRF-Token`
  header; `io.LimitReader` 64KB bodies; login on everything (guest 401);
  unviewable map = uniform 404. Spawn = one txn (tokens + initiative).
- Dice tray rolls via H2's roller (no new deps), ephemeral broadcast only
  (H2 owns `dice_logs`; nothing persisted here). Blind totals redacted per
  viewer on the wire AND in the POST response.
- A11y: listbox with roving tabindex (arrows select, Ctrl+arrows move,
  Home/End), text-coordinate mover, fog text equivalent, polite dice log +
  assertive fog status, focus-safe morphs (deferred past blur, never steal),
  44px targets, visible focus, reduced-motion guard, skip link, landmarks.
  Drag degraded to click-to-move per the plan's latency clause.
- Wiring amends (all explicit, minimal): serve.go registers VTT first-wins
  + maps snapshot path to `/api/vtt/` prefix (ownership check only knows
  exact/prefix patterns) + sets `web.VaultDir` (nothing ever set it: every
  live asset 404'd); F1 SSE loop fans out `VTTWireEvent`s via a dumb pipe
  (no web→vtt import cycle) with per-connection sidecar ACL + GM-pick.

Deviations from the plan text: none behavioral. Dice rolls intentionally
not persisted (H2 table ownership); token HP lives in app DB (board state)
while sheets stay vault truth (link-only).
