# P04 Data + Search Model

## Goal
Vault FS = truth, SQLite = fast secret-aware index.

## Scope
- Tables (index file): `vault_files, pages (frontmatter JSON), blocks {page_id, ordinal, secret} (chunk-level flags for FTS filtering), links, tags, optionals {id,title,file,line}`. Tables (app file): `users {name (immutable ID), role, password_hash, session_version}, groups {name}, group_members {group, user}, auth_sessions {id, user_id, expiry, last_seen, revoked}, login_attempts {ip, fails, locked_until}, edits_log (append-only who/what/when), characters (read index of sheet frontmatter + ruleset_id), sessions, events {date, session_id}` (fantasy calendar schema now, UI later), `wizard_drafts {token, payload}` (owner: Lane I1), `claim_tokens {token, slug, expires}` (owner: Lane C), `dice_logs` (owner: Lane H2), `vtt_maps {id, calibration}, vtt_tokens {map, token, x, y, hidden}, vtt_fog {map, mask}` (owner: Lane K). Files: `<name>.index.db` (disposable: temp+rename rebuild) + `<name>.app.db` (migrated, never rebuilt). Migrations contents owned by Lane B, runner by Lane E2. No `campaigns` table: one process serves one vault/campaign.
- `fsnotify` + startup rescan + manual reindex; clash detected via mtime/hash compare at `WriteFile` -> `*.conflict-<ts>.md` (single pattern everywhere).
- FTS5 over chunk text keyed by `(page_id, ordinal)` joined to `blocks.secret` + page ACL; query = FTS match → app-side ACL filter → snippet cut from visible chunks only. No per-role index in v1.
- Frontmatter in FTS: `title` + `tags` values indexed under the page's `secret` flag; all other frontmatter (stats, sheet data) excluded from FTS, stored in JSON only.
- Link graph + broken-link detector, secret-aware. Static SVG graph view in Wiki v1 (no interactive canvas).
- Clocks + quests: `clocks {session_id NULL, name, segments, filled}` (single campaign per process, no campaign_id), quest frontmatter `status: hook/active/done`. Schema now, full turn UI later.
- `campaign.yaml`: `base, overlay (+versions, display-only v1), enabled-features[]` (ruleset optionals) + `enabled-plugins[]` (feature plugins, separate namespace) schema + validation.
- Reindex atomic: build temp DB -> rename. Startup rescan + manual `reindex` command share one code path.

## Pass/fail
- Delete DB -> rebuild identical. Benchmark 5k-file vault in P01: cold rebuild + warm single-file rescan + filtered player search (target: seconds each, incl. Windows); record result, don't promise.
- Player search never returns secret titles/snippets.

## Out
Ruleset semantics (P05), VTT state (P08).
