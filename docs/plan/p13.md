# P13 Import / Export / Legal

## Goal
No lock-in, clean SRD handling.

## Scope
- Vault zip export/import (export: GM-only, logged; import: GM-only with zip-slip/symlink/size guards); `fixtures/srd/` snapshot ingest (user-maintained) with SRD 5.2 under CC-BY-4.0 attribution page shipped in the demo template (not the binary).
- Media: png/jpg/pdf fully supported; webp accepted stored-as-is (no maintained pure-Go decoder in the frozen set — no resize/thumbs for webp in v1). 5MB image / 10MB PDF caps, `assets/` conventions per subtree. Upload pipeline: stream to temp + MIME sniff (not extension), resize via stdlib + `x/image/draw` (CatmullRom; `disintegration/imaging` dropped as unmaintained), PDFs size-capped only (no page-count without a parser dep), Windows-reserved filename sanitization. EXIF orientation ignored in v1 (tag stripped; rotated phone photos need re-saving before upload).
- Template artifacts: `tutorial|demo` versioned zips from a pinned base URL (flag/env, checksum-verified, local cache with TTL + re-verify), fetch when online (P09), pinned versions. Binary stamps git sha/date via ldflags; template checks `needs-binary >=` on import.
- License: never ship copyrighted non-SRD text; document what GM may add privately. Full Monster Manual/spells are GM-imported homebrew, never bundled. `rules lint` warns (not fails) on likely non-SRD monster text in homebrew — GM owns table liability.
- Docs owned here: GM guide, player onboarding, plugin authoring, SRD attribution page.

## Pass/fail
- Export -> fresh `init --bare` + import = identical vault + index.
- Attribution present in demo template.

## Out
Full compendium conversion (needs P05 timebox first).
