# P03 Secrets + ACL

## Goal
Server-side secret + write-ACL enforcement everywhere.

## Scope
- Page: `secret:true/false` (default false). `owner` = username (usernames immutable in v1 — no rename; GM recreates user + `transfer-ownership` on change); `editable-by: [username|group:...]`. No `public` in v1 — non-secret = guest + member readable; secret = GM + `owner`/`editable-by` holders (owner always reads own pages; everyone else blocked). Block: `[!secret]-/+`, default `-`, visible to GM + page `owner`/`editable-by` when hidden from party.
- Redacted `[[secret-link]]` render (alias dropped — redacted block carries no title text), secret titles excluded from tree/search/tags/autocomplete/backlinks/graph/SSE/API. Unauthorized page fetches return uniform 404 (never 403) to all non-readers.
- `secret` OR-inherits from ancestors (fail-closed): a child without `secret:` is secret if any ancestor is. `editable-by` inherits like `owner` and confers read.
- Vault assets (images, PDFs, map backgrounds) served only through the ACL-checked asset handler with page-ACL check — never a raw static mount. A secret map's files are unreadable to guests/other players by URL guessing.
- Path ACL: full CRUD only under `characters/<pc>/...` for owner; `owner` inherits nearest-ancestor (PC root always stamped by wizard); `editable-by` exception; `../` traversal blocked.
- GM 1-click -/+ toggle (rewrites via atomic `vault.WriteFile` + reindex). Player create/edit validated on write (same helper).
- Conflict files `*.conflict-<ts>.md` indexed with `status: conflict` + parent's ACL, excluded from search/links/graph/tags; visible only in owner's/GM diff banner. Rule precedence: never-widen always wins — orphan conflict (no parent found) defaults to writer + GM only.

## Pass/fail
- Leak audit checklist: render, FTS body + snippets, tags, graph, autocomplete, embeds (incl. embed-of-secret), SSE events + replay, API, print, zip. Test matrix GM / owner / editable-by-non-owner / other-player / guest / revoked-session × secret/non-secret / +/- / conflicted-file. Writes always require login; reads: non-secret open, secret GM+owner/editable-by only.
- GM preview-as-player: `Viewer.preview_as` (GM sessions only, bannered + logged) renders any view through that role's filter — the P00 toggle's model.
- Write-escape attempts rejected.

## Out
Per-player `for=` + audit view -> `secrets-advanced` plugin (P06).
