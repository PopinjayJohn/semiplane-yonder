# P07 Campaign Manager UX (incl. Character Wizard)

## Goal
Campaign lifecycle + new-player-friendly creation inside CM.

## Scope
- IA: this vault's campaign content — sessions, journals, NPCs/PCs, GM vs player nav. One process = one campaign: no in-app campaign switcher (header shows campaign name only); create/archive/clone are vault-directory ops (CLI + file manager). Each slice usable standalone.
- Campaign ops (vault-directory level): create/archive/clone via CLI (`init`, `archive-vault`, `clone-vault`) + file manager; `campaign.yaml` edit, character ownership transfer (`transfer-ownership`).
- GM setup wizard (matches player wizard): picks system/overlay/optionals on `init`, writes `campaign.yaml`. Optionals UI entry point.
- `character-wizard` plugin at `/c/<token>/create`: shareable single-use claim token (GM-issued per slug) lets the invited player create + stamp `owner:` without pre-existing rights; redemption invalidates the token. Steps from active overlay (ancestry/class/background/stats) -> preview -> writes `characters/<pc>/index.md` (sheet in frontmatter; SQLite is read index) + stamps `owner:` to creating player + draft/resume in SQLite.
- Simple view is the default antidote to source fear (P07 ships it with the wizard); Advanced editor opt-in with validation.
- Player subpage CRUD boundaries communicated in UI.
- Player home `/me` (sheet-first, not wiki-first): my sheet + HP/slots tap targets, my handouts, last-session recap, loot/level badges. Default landing for player role.
- Simple / Advanced sheet: Simple hides source (buttons/pips only, `PATCH /characters/:id/fields` surgical frontmatter edit); Advanced reveals MD+frontmatter with schema validation. Preference sticky per user.
- Level-up + rest flow in Simple view: level buttons, short/long rest (HP/hit-dice/slot recovery) writing back to sheet MD via `vault.WriteFile` (re-read before write). No raw frontmatter needed.
- GM run dashboard (v1): one page with initiative + selected token HP + secret -/+ toggles + dice log + session notes + timers. Assembles P08/P12/P03 pieces, no new state.
- Encounter builder: pick compendium monsters -> builds encounter, emits spawn **intent** (Lane K executes: writes tokens + initiative in one action) + mass HP adjust + loot drop into session note.
- Session template `sessions/<date>.md`: hooks, scenes, secrets-to-reveal, loot + auto-recap (toggles flipped, clocks advanced, XP/loot added).

## Pass/fail
- New player completes wizard with no help, character appears in own tree only.
- Clone campaign preserves optionals + secrets state.

## Out
VTT (P08), dice grammar (P12).
