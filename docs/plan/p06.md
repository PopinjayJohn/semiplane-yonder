# P06 Plugin SDK (Feature / UI / Ruleset)

## Goal
Lean core, compiled-in extensions with strict contracts.

## Scope
- Kinds: Ruleset (data, hot-reload) / Feature (Go: random-tables first example incl. d100 sidebar slot with one-click insert into session note, then initiative-tracker, vtt-maps, character-wizard, secrets-advanced) / UI (templ slots). Initiative state/logic lives in initiative-tracker; VTT renders the order + feeds token HP.
- Go interfaces: `Feature{ID, Routes, Publish}`, `SheetRenderer`, `BlockRenderer`, `RulesetDef`. `init()` registry + `--plugins=` flag + per-campaign `enabled-plugins[]` (namespace separate from ruleset `enabled-features[]`).
- Slots: `header-*, sidebar-left/right, footer, page-actions, sheet-header` with `{component, priority, show-if}`. GM disable. SSE-patchable, secret-filtered input only.
- CSS contract: core tokens (`--bg/--surface/--fg/--muted/--accent/--border/--radius/--font`) + `@layer core, plugins, overrides`. Plugin CSS in `@layer plugins`, prefixed `[data-plugin="<id>"]`, no bare element selectors, no `!important`, 20KB cap. `plugin check` lints this. Themes = token overrides via `[data-theme]`; P00 loser ships as alt theme.
- A11y contract (WCAG 2.2 AA target): semantic landmarks/nav/main/complementary, every slot keyboard-reachable with visible focus, redaction badges never color-only (text label), token contrast checked per theme, `prefers-reduced-motion` disables SSE pulse/animations. `plugin check` fails on missing labels/landmarks.
- `secrets-advanced` grammar locked: `> [!secret|for=alice,group:party]` + shared `edits_log` table (P04/P10: same schema/store as the append-only who/what/when log). Build deferred, interface here. Covers whispers + timed handout push (private reveal to one player).

## Pass/fail
- New feature added without touching core routes; disabled plugin leaves no UI trace.
- UI plugin cannot access unfiltered secret data (code review + test).

## Out
Individual plugins' logic (P07/P08/P12).
