# P02 Markdown / Obsidian Compat

## Goal
Exact supported syntax + round-trip safety. Vault files remain editable in Obsidian.

## Scope
- goldmark + goldmark-obsidian: `[[wikilink|alias]]`, `![[embed]]`, `#tags`, tasks, footnotes, GFM tables. Page ID = vault-relative posix path (lookup case-insensitive, display preserving); rename = delete + create.
- Custom: `> [!secret]-/+`, `> [!optional|id=...]`, `<!-- optional:id=... -->` (the `> [!unsupported]` placeholder below is system-rendered, never authored).
- YAML frontmatter keys (closed set, extension only by amend): `title: string`, `secret: bool=false`, `owner: username (immutable)`, `editable-by: [username|group:...]`, `optional: bool|{id}`, `tags: [string]`, `status: hook|active|done|conflict`, `parent: path` (conflicts), `writer: username` (conflicts), `ruleset_id: string` (sheets), `version: string` (rules packs, display-only v1), `content-warning: [string]` (reserved, backlog). Sheet stat keys live under `sheet:` namespace. Unknown keys fail `rules lint`; bad types quarantine (never crash).
- Unsupported inventory: Dataview, Canvas, DataviewJS — stripped in view and replaced with a system-rendered `> [!unsupported]` placeholder (users don't author it), preserved in source.
- Fixtures: real SRD excerpt + edge cases (nested callouts, wikilink in callout title, CRLF, Windows paths, invalid YAML/frontmatter types → quarantine, never crash).
- Golden tests: `testdata/markdown/{input.md, expected.html, expected-index.json}` per case, run in CI. Round-trip test: parse->render never rewrites source.

## Pass/fail
- Round-trip test: parse->render never rewrites source file.
- Fuzz corpus of vaults renders without panic, unsupported shows placeholder.

## Out
Secrets enforcement (P03), search (P04), editor UI (P01).
