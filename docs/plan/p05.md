# P05 Ruleset DSL (Base + Overlay + Homebrew)

## Goal
Prove data-only rulesets without Go recompile. Timeboxed.

## Scope
- Layers: `Base (dnd, coc)` + `Overlay (5e-2014, 5e-2024, coc-6e/7e)` + Homebrew diff (never forks overlay).
- Format: YAML/JSON schema (stats, derived, rolls, dice_types/faces/symbols + grammar + renderer, identity {portrait, pronouns, voice/notes, inspiration, death-saves}) + MD content + sheet layout ref. `campaign.yaml` records base/overlay names (display-only v1). Base declares dice semantics as config + data rules; core's generic engine executes them (P12).
- Optionals multi-per-file: `<!-- optional:id=... -->` + `[!optional|id=...]` (explicit id required on blocks), `optional:true` shorthand with id = path slug. Id uniqueness checked vault-wide, indexed, GM per-id toggle -> `campaign.yaml`.
- Timebox proof: Fighter + Goblin + 1 spell from SRD snapshot to playable sheet. Full compendium explicitly out.
- Homebrew authoring doc: no-code line defined (MD+YAML only, `rules lint`).
- Evaluator (v1 locked): tiny hand-rolled integer/boolean engine in core (arithmetic, comparisons, floor, min/max, keep-highest/lowest) executing base-supplied data rules — zero new deps, no I/O so safe by construction on GM-supplied vault content (players can't write rules). Bounds: max depth 32, max 256 literals, 64-bit checked arithmetic (overflow fails closed). Powers derived stats + hook policies + symbol cancellation tables. Full expression language explicitly later (see backlog). Unknown functions fail `rules lint`.
- Intents + hooks (ruleset-defined, never hardcoded): each Base declares its intent catalog (`dnd`: attack/save/check/damage/heal/initiative/rest-short/rest-long/death-save/concentration; `coc`: skill-push/sanity/etc.; others per base). Overlays/homebrew add intents. Core envelope only: `{intent, actor, targets, tool, context}`.
- Hook = intent + phase (`pre-roll, post-roll, interpret`). Receives intent + modifier list, returns `{source, label, value}` additions. Layers compose `base -> overlay -> homebrew`; conflicts by per-key policy (damage: sum, advantage: cancel, crit-range: narrowest-wins; unknown keys fail `rules lint`). VTT posts spatial context; base maps it to meaning (flanking vs move-with-forward). Full ordered modifier list pinned in log.

## Pass/fail
- Switch overlay 5e-2014->2024 changes sheet/rolls with no rebuild.
- Duplicate optional id fails validation with file:line.

## Out
Sheet theming (P06), wizard flow (P07).
