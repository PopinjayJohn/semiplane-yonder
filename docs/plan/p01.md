# P01 Tech Spike + Clickable Prototype

## Goal
Prove the stack can do the P00 visuals for real, with no rules/VTT yet.

## 1. Scaffold (locked)
- Go 1.27, module path fixed at init (pin exact dep versions in go.mod). Tree: `cmd/app, internal/{vault,markdown,secrets,ruleset,dice,plugins,web,auth,store}, web/{templates,static/{core,themes,vendor,mockups}}, fixtures/{p01,srd,rules}, testdata/`.
- `go:embed` static/templates (incl. vendored `web/static/vendor/` — datastar.js + CodeMirror pinned by version + SHA256 in `web/static/vendor/VERSIONS`, downloaded in CI with checksum verify, committed fallback for offline builds), `goreleaser` stub for Linux/macOS/Windows, Makefile (`dev`, `build-all`). System fonts only.
- Codegen: `templ generate` in `make dev` + CI verifies with `git diff --exit-code` after generate (dirty fails). No sqlc — hand SQL.
- Dev loop pinned: `make dev` = `templ generate --watch` + `go run ./cmd/app --vault fixtures/p01`. No `air`.

## 2. Spike decisions (must exit with a pick)
- SQLite driver locked: modernc (pure Go) — cross-compile matrix + FTS5 sanity. Pragmas locked: `WAL, busy_timeout=5s, foreign_keys=ON, synchronous=NORMAL` via DSN, dedicated single-writer connection (reads from pool; `MaxOpenConns` is per-pool), checkpoint on graceful shutdown.
- `fsnotify` watcher indexes conflict files as `status: conflict` (parent ACL, hidden from search); debounce 200ms, ignore `*.db`/`.sessionkey`/build dot-dirs only.
- templ + Datastar SSE hello: GM `-/+` flip updates player pane, no auth.

## 3. Clickable prototype (from old P00 functional scope)
Serve `fixtures/p01/*.md` from disk:
- Shell from winning P00 variant, real slots rendering (`header-right, sidebar-left/right, footer, page-actions, sheet-header`).
- Non-secret vs secret page gate with hardcoded users (real auth is P11). Non-secret readable logged-out; secret GM + owner/editable-by only.
- Secret filter server-side: `-` hidden, `+` shown, titles excluded from search/tree/autocomplete, `[[secret]]` = redacted.
- Character subpage create under own PC only (prefix check, writes via atomic `vault.WriteFile`).
- Editor: textarea + server preview, `-` red / `+` green, `[!unsupported]` placeholder, conflict banner faked.

## Pass/fail
- `go run ./cmd/app --vault fixtures/p01` works offline.
- Guest sees non-secret, blocked on secret page.
- `-/+` toggle propagates via SSE.
- Cross-compile produces 3 binaries.
- modernc choice + pragmas recorded (decision made; verify in matrix).

## Out of scope
Real auth (P11), dice (P12), VTT drag (P08), ruleset DSL (P05), migrations, WYSIWYG.
